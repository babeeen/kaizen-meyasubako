# カイゼン目安箱

自治体・非IT企業（製造業・建設業・医療福祉・小売など）の現場から、
業務改善アプリへの「切実な要望・課題」を集めるための投書板アプリ。
ハッカソン練習用のデモです。

## 使い方

- `index.html` をブラウザで開くだけで動きます（ビルド不要・依存なし）。
- ローカルサーバーを使う場合：
  ```
  python -m http.server 8642
  ```
  → http://localhost:8642

## 機能

| 機能 | 説明 |
|---|---|
| 投書一覧 | 伝票風カード。ステータスはハンコ風スタンプ（受付／検討中／採択／開発中／解決済） |
| 絞り込み | 組織タブ（自治体・製造業…）× カテゴリチップ × キーワード検索 |
| 並び替え | 新着順／共感が多い順／切実な順（影響度×頻度で算出） |
| 共感 | 「うちも困ってる」ボタン。切実さを開発者に伝える |
| 詳細 | 申請書風モーダル。現状のやり方／何がつらいか／こうなったら最高 |
| 解決事例 | 解決済の投書には「どう解決したか」（導入したもの・費用感・効果）を掲載 |
| 追記 | 各投書への現場からの補足コメント |
| 投書 | 様式第1号「業務改善 投書票」フォームから新規投稿 |

投稿・共感・追記は `localStorage` に保存されます（デモのためこの端末のみ）。
リセットしたい場合はブラウザの開発者ツールで
`localStorage.clear()` を実行してください。

## ファイル構成

```
index.html   … マークアップ
style.css    … デザイン（和紙×朱印のエディトリアルテーマ）
data.js      … シードデータ（現場で実際にありそうな課題 20件。うち5件は解決事例）
app.js       … 一覧描画・絞り込み・投稿・共感・保存ロジック
```

## デザインコンセプト

江戸時代の「目安箱」がモチーフ。
和紙の質感（生成りの紙色＋粒状ノイズ＋方眼罫線）に、
ハンコの朱色（朱）と藍色をアクセントとして使用。
ステータススタンプは SVG turbulence マスクでインクのかすれを再現。

- 見出し: Shippori Mincho B1
- 本文: Zen Kaku Gothic New
- 数字: IBM Plex Mono
